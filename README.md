# HiveYard

Apiary desk for a ten-yard beekeeping co-op. Keepers track colonies, harvests, and inspections locally — no public license file, no external API, no cloud account.

Owned and maintained by Abraham (`@AbrhamDemsew`).

## Scripts

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

Requires Node.js 20.
